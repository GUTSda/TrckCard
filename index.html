Apa itu Trackcard?

Trackcard adalah game kartu kompetitif dengan konsep batu gunting kertas: kamu harus mengalahkan musuh dengan menang batu gunting kertas dan menghancurkan lawanmu lewat kombinasi kartu Unitdan, Skill. Setiap ronde berdurasi singkat sehingga satu match terasa padat dan seru.

Durasi Cepat

Rata-rata 5–10 menit per match. Cocok buat main cepat atau ketika gadgetmu di charge.

Strategi Dalam

Deckbuilding fleksibel:Fleksibel build deck untuk melawan musuh.

Mudah dikuasai

Game yang mudah dikuasai pemain

Cara Main (Ringkas)

Berikut alur umum permainan. Versi lengkap tersedia di Rules.

Setup

Kedua pemain mulai langsung dengan 10 kartu. Batu Gunting Kertas untuk mendapat giliran menyerang, dilakukan setiap ronde. Pastikan deck minimal 10 kartu.

Phase Giliran

Batu Gunting Kertas → Main Unit/Skill → Serang → End.

Menang

Hancurkan semua kartu musuh atau curi kartu musuh. Beberapa kartu punya kondisi menang alternatif.

FAQ
